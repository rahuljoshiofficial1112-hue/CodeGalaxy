# Getting Started with GitHub Copilot

## Running Tests

Install the dependencies and run the backend test suite from the repository root:

```bash
python -m pip install -r requirements.txt
python -m pytest -q
```

The tests use FastAPI's `TestClient`, so a running application server is not required. API state is held in memory and reset between tests.
